🖥️ 1. Frontend README (/frontend)
🎓 University Chatbot - Frontend
The user interface for the University RAG system is built to provide a seamless, responsive chat experience for students and staff.

🛠️ Tech Stack
Framework: React.js / Next.js

Styling: Tailwind CSS

API Client: Axios

Icons: Lucide-React / Heroicons

🚀 Features
Real-time Chat: Interactive message bubbles with user and AI differentiation.

Markdown Support: Correctly renders formatted text from the LLM.

Source Citations: Displays document snippets used to generate the answer.

Loading States: Visual indicators while the AI is "thinking."
